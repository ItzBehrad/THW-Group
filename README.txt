THW GROUP WEBSITE
=================
محتویات:
- index.html: صفحه اصلی
- news.html: اخبار روبلاکس
- fa-news.html: اخبار فارسی
- about.html: درباره THW Group
- style.css: طراحی مشترک مشکی و سبز نئونی
- script.js: منوی موبایل و سال پانوشت
- articles/: دو صفحه مقاله نمونه

مشاهده:
۱. ZIP را از حالت فشرده خارج کن.
۲. روی index.html دوبار کلیک کن.

انتشار با GitHub Pages:
۱. فایل‌های داخل پوشه را در مخزن GitHub بارگذاری کن.
۲. Settings و سپس Pages را باز کن.
۳. انتشار از شاخه main و پوشه ریشه (/) را انتخاب و ذخیره کن.

نکته: تاریخ‌های پروژه در صفحه «درباره ما» بر اساس اطلاعات ارائه‌شده از سوی تیم هستند و تأیید مستقل محسوب نمی‌شوند.
